# Hébergement sur Homelab et exposition publique via Tailscale Funnel

## Contexte
L'Espace Lutin doit être accessible en HTTPS public pour que les Lutins puissent se connecter sans installer de VPN ni créer de compte, via le Lien magique reçu par courriel d'Annonce. L'organisateur dispose d'un Homelab fonctionnant 24h/24 avec Dockge et d'un nœud Tailscale déjà configuré avec Tailscale Funnel actif (`homelab.tail7d8b91.ts.net`), mais ne possède pas de compte Cloudflare ni de nom de domaine dédié.

## Décision
1. **Hébergement et orchestration** : L'Espace Lutin est déployé sous forme de conteneur Docker orchestré par Dockge dans `/opt/stacks/pere_noel_fremo` sur le Homelab.
2. **Persistance et port local durci (Loopback)** : Le répertoire `res/` (contenant la base SQLite `res/fremo.db`) est monté en volume persistant. Le port du conteneur est expressément lié à l'adresse de bouclage IPv4 de l'hôte (`127.0.0.1:8000:8000`), empêchant toute exposition directe non filtrée sur le réseau local physique. *Amendé le 16 octobre 2026 : le service d'administration `pere_noel_fremo_admin` (ADR-0013) est lui aussi lié en loopback (`127.0.0.1:8001:8001`) ; aucun port n'est publié sur le réseau local, l'organisateur passant par Tailscale même à domicile.*
3. **Exécution sous utilisateur non privilégié** : Le conteneur ne s'exécute pas en `root`. Un utilisateur dédié non privilégié `lutin` (UID/GID 1000) possède les répertoires `/app/res` et `/app/logs` et exécute le processus FastAPI (`USER lutin`).
4. **Masquage des jetons magiques dans les journaux d'accès** : Afin d'éviter la fuite de secrets dans les journaux d'accès HTTP (`uvicorn.access`), un filtre de journalisation (`TokenMaskingFilter`) est actif par défaut sur la commande `serve` pour obfusquer les motifs `/lutin/<token>` et `/api/lutin/<token>` en `/lutin/***` et `/api/lutin/***`.
5. **Exposition publique (Tailscale Funnel)** : Le service est exposé publiquement sur Internet sans ouverture de port de box ni achat de domaine via Tailscale Funnel sur le port 10000 : `https://homelab.tail7d8b91.ts.net:10000` ciblant `127.0.0.1:8000`. *Amendé le 16 octobre 2026 : l'Espace Admin est servi à part, réservé au tailnet, via `tailscale serve` sur le port 8444 (`https://homelab.tail7d8b91.ts.net:8444` ciblant `127.0.0.1:8001`). Le port 8444 est choisi hors des ports acceptés par Funnel (443, 8443, 10000), pour qu'aucune commande `tailscale funnel` ne puisse l'exposer par erreur.*
6. **Base URL** : L'URL racine permanente configurée dans `res/secure_data.yml` pour forger les Liens magiques est fixée à `https://homelab.tail7d8b91.ts.net:10000`.
7. **Centralisation de l'administration** : Les commandes CLI d'administration (`pere-noel annonce`, `pere-noel tirage`, audit) sont exécutées directement sur le Homelab accédant à `res/fremo.db`.
